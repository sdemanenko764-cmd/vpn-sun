# vpn-sun

Sun VPN — desktop-клиент для Windows.

## Скачать

Папка [`downloads`](downloads):

- `Sun-VPN-<версия>-Windows-x64-setup.exe` — установщик (рекомендуется): ярлыки, удаление через «Приложения», автообновление.
- `Sun-VPN-<версия>-Windows-x64.exe` — переносная версия без установки (тоже обновляется сама).
- `Sun-VPN-<версия>-source.zip` — исходники; Windows-сборки собирает GitHub Actions из этого архива.

`downloads/latest.json` — манифест последней версии, его читает встроенное автообновление.
